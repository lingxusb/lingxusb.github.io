# Bin Shao — Personal Website

Simple static site. Just plain HTML + CSS. No build step.

## Files
- `index.html` — Home
- `people.html` — People
- `publications.html` — Publications
- `software.html` — Software
- `news.html` — News
- `style.css` — Shared styles
- `images/profile.jpg` — Profile photo (you need to add this)

## Editing
Edit the `.html` files directly. Each page has the same header/nav — if you add a new page, update the `<nav>` block in all files.

## Local preview
Open `index.html` in a browser, or run a simple server:
```
python3 -m http.server 8000
```
then visit http://localhost:8000
